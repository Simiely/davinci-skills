# 案例：3D 玻璃渲染的时域闪烁（2026-11-01）

> 一次真实的完整排查过程，包括**我判错的一轮**。留档是为了以后不再重复走弯路。

## 场景

- 素材：37 秒 / 1920×1080 / 30fps / H.264，编码器标记 `Blackmagic Design DaVinci Resolve Studio`
- 成片结构：8 个硬切镜头（切点 3 / 6 / 11 / 17 / 20 / 23 / 27 秒）
- 用户描述："第 6 个片段和第 7 个片段有一些闪烁"→ 后来明确："**21~27 秒之间都有，是原始素材的抖动**"
- 补充关键信息："**这个是三维渲染素材，玻璃渲染出来的闪烁**"

## 第一轮：误判（错误路径，别重走）

用 16×16 块统计帧间差，最大块稳定落在**画面左下角**，单帧跳变 **±18 级**（全画面中位 6.2）。于是判定那里是闪烁源，并做了两轮"高光肩部"LUT 压制。

**结果**：

| 措施 | 效果 |
|---|---|
| 肩部把 255 压到 234 | 死白面积 0.03% → 0，但热点抖动 **8.36 → 8.02（−4%）** |
| 逐档加强肩部（K=0.45/M=0.70） | 抖动 −30.4%，**白点崩到 178**，画面发灰 |

**误判原因**：左下角其实是**前景树枝 + LED 灯串**在镜头前扫过——那是**运动**，不是噪点。块级最大差对运动极其敏感，是最容易踩的坑。

## 第二轮：正确诊断

换成"改前/改后同一区域的**逐像素**帧间活动量比值"，并让用户自己动手加了降噪节点（S6/S7 各加一个节点 + 「降噪」），再对比两版渲染：

| 指标 | v3（无降噪） | v4（有降噪） | 变化 |
|---|---|---|---|
| 玻璃区（块 15–18 / 9–10，画面中右） | 7.7–8.5 | 6.0–6.8 | **−15% ~ −21%** |
| 块 (16,10) 单块 | 8.45 | 6.78 | **−19.9%** |
| 全画面 | 3236 | 3105 | −4.0% |
| 玻璃区亮度均值 | 137.7 | 137.8 | 不变（无偏色/不变亮） |

## 各方案实测（用于以后决策）

| 方案 | 实测 | 结论 |
|---|---|---|
| LUT 压高光（多档） | −2.9% ~ −30.4%，白点 235→178 | 不可用 |
| ffmpeg `atadenoise` | 噪声指数 4.18 → 4.14 | 无效 |
| ffmpeg `hqdn3d`（时域 6） | 4.18 → 4.11 | 无效 |
| Resolve 节点「降噪」 | 玻璃区 −15%~−21% | **有效** |

## API 能力边界（实测证据）

1. 运行时反射 `Graph` 对象只有 11 个方法：`ApplyArriCdlLut / ApplyGradeFromDRX / GetLUT / GetNodeCacheMode / GetNodeLabel / GetNumNodes / GetToolsInNode / ResetAllGrades / SetLUT / SetNodeCacheMode / SetNodeEnabled` —— **没有 AddNode，也没有任何 NR 参数接口**。
2. `TimelineItem.GetNodeGraph()` 能读到节点数变化（1 → 2）和 `GetToolsInNode(2) == ['降噪']`，但**读不到帧数/阈值**。
3. Fusion 侧 `AddFusionComp()` 可用，但注册表里没有降噪类工具：试过 `Denoise / TemporalNR / TemporalNoiseReduction / SpatialNR / Deflicker / TimeAverager / Trail / Echo / Median` 全部返回 `None`；可用的只有 `Blur / VectorMotionBlur / TimeStretcher / BrightnessContrast / ColorCorrector`。

⇒ 结论：**"加节点 + 开降噪"这一步必须人在 UI 里点**，脚本只能做前后验证。分工：人点两下，脚本给数字。

## 经验

1. 用户说"闪烁"和"抖动"可能是同一件事，先问**具体秒数**，不要拿整段做统计。
2. 判断噪点必须用**同区域、同帧段、改前/改后**的活动量比值；单看绝对值会被运动骗。
3. 想清楚"素材里有没有"再动手：源素材同一段跑一遍，和成片对比，能立刻分开"素材问题"和"编码问题"。
4. 三维渲染的玻璃/焦散闪烁属于**时域不收敛**（蒙特卡洛噪点每帧位置不同 + 逐帧独立降噪），后期只能压、不能消。
